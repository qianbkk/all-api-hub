# 权限管理（可选权限）

> 可选 Cookie、Web Request 等权限只在人工验证接力或需要带认证信息的站点请求中使用。它们默认不授予，日常离线功能不依赖这些权限。

## 功能概览

- **集中管理**：在“权限管理”页面查看、授予或撤销扩展的可选权限。
- **支持人工验证接力**：用户主动执行识别或刷新并遇到站点验证时，可在临时页面由本人完成验证，再继续原操作。
- **不会自动绕过**：这些权限不用于破解 CAPTCHA、伪造设备信号、轮换 IP 或规避站点安全机制。
- **随时可撤销**：关闭可选权限不会影响核心离线管理能力。

## 设置入口

1. 打开扩展并进入 **设置**。
2. 当浏览器支持可选权限时，打开 **权限管理 / Permissions**。
3. 查看每项权限的用途和当前状态，再决定是否允许。

## 常见权限

- **Cookies**：在你已连接的站点域名上读取必要的会话 Cookie，以便用户完成验证后继续同一会话中的请求。
- **Web Request**：判断请求是否被站点拦截，以及是否需要提示用户打开临时验证页面。
- **Web Request Blocking**：在浏览器允许且工作流确有需要时，为已授权站点请求附加必要的认证信息。

扩展不会使用这些权限扫描无关站点；使用范围限于你已连接的站点和你发起或明确启用的工作流。

## 安全默认值

- 权限必须由用户在浏览器弹窗中明确确认。
- 后台自动任务使用临时验证页面的能力默认关闭。
- 自动刷新默认不使用人工验证接力。
- 手动刷新、设置页、侧边栏和弹出页入口可独立配置。
- 站点要求滑块、图片点选、Turnstile 等验证时，必须由用户本人完成。

## 何时考虑授权？

可在以下场景按需授权：

- 手动识别或刷新站点时经常需要在同一浏览器会话中完成站点验证。
- Firefox 等浏览器需要额外权限才能在验证后保留必要的会话状态。

以下场景可以保持关闭：

- 仅使用离线管理、价格查看或手动录入功能。
- 站点不需要额外安全验证。
- 你不希望扩展读取站点 Cookie 或观察相关请求。

## 隐私与撤销

- 账号与站点配置默认存储在浏览器本地；网络请求仅按你启用的功能发起。
- 可在权限管理页点击“撤销”，或在浏览器扩展管理界面移除权限。
- 撤销后，依赖这些权限的人工验证接力可能不可用，但其他核心功能仍可使用。

## 故障排查

- **点击允许后没有反应**：检查地址栏附近是否有被拦截的权限弹窗。
- **临时页面未打开**：检查弹窗设置和对应页面入口是否已允许使用人工验证接力。
- **验证后仍失败**：重新登录站点，确认账号或令牌有效，并降低请求频率。
- **后台任务没有弹窗**：这是默认安全行为；后台自动任务不会主动要求用户完成验证。
