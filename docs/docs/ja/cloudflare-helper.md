# サイト手動確認リレー

> Cloudflare、Turnstile、その他ユーザー操作が必要なサイト確認に使用します。個人版は隔離された一時ページを開き、確認後に元の処理を続行するだけです。CAPTCHA の解除、デバイス情報の偽装、サイトの安全機構の自動回避は行いません。

## 概要

- **必要時に一時ページを開く**：手動認識や手動更新など、ユーザーが開始した操作で確認が必要になった場合、対象サイトをタブまたは一時ウィンドウで開けます。
- **ユーザー本人が確認する**：スライダー、画像選択、Turnstile などが表示されたら、一時ページへ切り替え、サイトの案内に従って本人が操作します。
- **確認後に続行**：サイトが現在のブラウザーセッションを受け入れた後、拡張機能は元の認識または更新処理を続行できます。
- **安全な既定値**：バックグラウンド自動処理で一時確認ページを使う機能は既定で無効です。自動更新も既定では使用しません。ポップアップ、サイドパネル、設定ページからの利用は個別に制御できます。
- **サイト単位のレート制限**：一括更新やチェックインでは、引き続きサイト単位のレート制限と範囲付きの時間差を適用します。

## 使用手順

1. 対象サイトにログインし、拡張機能で「自動認識」または手動更新を実行します。
2. サイト確認が必要という案内が表示されたら、一時ページを開きます。
3. そのページへ切り替え、ユーザー本人がサイトの確認を完了します。CAPTCHA 解除、代理回答、自動クリックツールは使用しないでください。
4. 確認後に拡張機能へ戻ります。元の処理が続行されない場合は、手動で一度だけ再試行してください。
5. 確認が繰り返される場合は再試行を止め、更新間隔を広げ、アカウントやアクセス制限をサイトへ確認してください。

## 開き方

**設定 → データ更新** で一時確認ページの開き方を選択できます。

- **現在のウィンドウのタブ**：既存ウィンドウに非アクティブタブとして追加し、作業の中断を抑えます。
- **独立した一時ウィンドウ**：より分離された閲覧コンテキストを使えますが、ブラウザーが前面に出る場合があります。

どちらの方式でも、確認はユーザー本人が手動で完了する必要があります。

## 安全上の注意

- IP ローテーション、デバイスフィンガープリント偽装、CAPTCHA 解除は行いません。
- サイトがセッションを受け入れることは保証できません。サイト側のリスク管理、アカウント状態、ネットワーク状態が優先されます。
- オプションの Cookie / Web Request 権限は、ユーザーが許可し、選択した処理で必要な場合にのみ使用します。いつでも取り消せます。
- 一時ページがブロックされた場合は、短時間に繰り返さず、拡張機能の権限とポップアップ設定を確認してください。

## トラブルシューティング

| 状況 | 対応 |
| --- | --- |
| 一時ページが開かない | ブラウザーがポップアップをブロックしていないか、必要なオプション権限を許可したか確認します。 |
| 「Just a moment」のまま進まない | サイトの確認を待ち、操作が求められた場合は本人が完了します。進まない場合は中止して後で再試行します。 |
| 確認後も 401/403 になる | サイトへ再ログインし、アカウントまたはトークンが有効か確認してから手動で再試行します。 |
| 自動タスクで確認ページが開かない | 個人版の安全な既定値です。バックグラウンド自動処理は手動確認リレーを開始しません。 |
| 429 が繰り返される | 更新間隔を広げ、同時処理や一括処理を減らし、サイトの制限に従います。 |
