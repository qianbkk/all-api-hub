# 権限管理（オプション権限）

> オプションの Cookie / Web Request 権限は、手動確認リレーまたは接続済みサイトへの認証付きリクエストでのみ使用します。既定では付与されず、主要なオフライン機能はこれらの権限に依存しません。

## 概要

- **一元管理**：権限ページでオプション権限を確認、付与、取り消しできます。
- **手動確認リレー**：ユーザーが開始した認識や更新でサイト確認が必要になった場合、一時ページで本人が確認を完了し、元の処理を続行できます。
- **自動回避は行わない**：CAPTCHA の解除、デバイス信号の偽装、IP ローテーション、サイトの安全機構の回避には使用しません。
- **いつでも取り消し可能**：オプション権限を無効にしても、主要なオフライン管理機能には影響しません。

## 設定へのアクセス

1. 拡張機能を開き、**設定**へ移動します。
2. ブラウザーがオプション権限をサポートする場合、**権限管理 / Permissions** を開きます。
3. 各権限の目的と現在の状態を確認してから許可します。

## 主な権限

- **Cookies**：接続済みサイトのドメインで必要なセッション Cookie を読み取り、ユーザー確認後も同じセッションで処理を続けます。
- **Web Request**：リクエストがブロックされたか、一時確認ページを案内する必要があるかを判断します。
- **Web Request Blocking**：ブラウザーが対応し、選択した処理で必要な場合に限り、許可済みサイトへのリクエストへ必要な認証情報を付加します。

これらの権限で無関係なサイトをスキャンすることはありません。対象は接続済みサイトと、ユーザーが開始または明示的に有効化した処理に限られます。

## 安全な既定値

- ブラウザーの権限ダイアログでユーザー本人の確認が必要です。
- バックグラウンド自動処理で一時確認ページを使う機能は既定で無効です。
- 自動更新は既定で手動確認リレーを使用しません。
- 手動更新、設定ページ、サイドパネル、ポップアップからの利用は個別に設定できます。
- スライダー、画像選択、Turnstile などはユーザー本人が完了する必要があります。

## いつ許可するか

必要な場合だけ許可してください。

- 手動認識や更新で、同じブラウザーセッション内のサイト確認が頻繁に必要になる場合。
- Firefox などで、確認後のセッション状態を保持するために追加権限が必要な場合。

次の場合は無効のままで構いません。

- オフライン管理、価格確認、手動入力だけを使用する場合。
- サイトが追加の安全確認を要求しない場合。
- 拡張機能によるサイト Cookie の読み取りや関連リクエストの監視を許可したくない場合。

## プライバシーと取り消し

- アカウントとサイト設定は既定でローカルに保存され、ネットワーク通信は有効にした機能に必要な範囲で行われます。
- 権限ページまたはブラウザーの拡張機能管理画面からいつでも取り消せます。
- 取り消し後は手動確認リレーを必要とする処理が使えない場合がありますが、他の主要機能は引き続き利用できます。

## トラブルシューティング

- **許可を押しても反応しない**：アドレスバー付近にブロックされた権限ダイアログがないか確認します。
- **一時ページが開かない**：ポップアップ設定と、現在の画面から手動確認リレーを使える設定か確認します。
- **確認後も失敗する**：サイトへ再ログインし、アカウントまたはトークンが有効か確認し、リクエスト頻度を下げます。
- **自動タスクがページを開かない**：安全な既定動作です。バックグラウンド自動処理はユーザー確認を要求しません。
