# 個人版のインストール方法と更新

All API Hub 個人強化版は `qianbkk/all-api-hub` からのみ公開されます。ブラウザストアにある同名拡張機能はアップストリームが管理しており、この個人版ではありません。

::: tip かんたんな結論
日常利用には [個人 Stable](https://github.com/qianbkk/all-api-hub/releases/latest) を使用してください。変更を先行確認するときだけ [Nightly](https://github.com/qianbkk/all-api-hub/releases/tag/nightly) を使用します。どちらも手動でインストールおよび更新します。
:::

## どのバージョンをインストールすべきですか？

| 状況 | おすすめ | 更新方法 |
|---|---|---|
| 日常の安定利用 | [個人 Stable](https://github.com/qianbkk/all-api-hub/releases/latest) | 新しいパッケージをダウンロードして手動再インストール |
| 修正や機能の先行テスト | [個人 Nightly](https://github.com/qianbkk/all-api-hub/releases/tag/nightly) | 手動更新。安定しない場合があります |
| 開発、監査、カスタマイズ | [個人リポジトリのソース](https://github.com/qianbkk/all-api-hub) | 自分で取得、ビルド、読み込み |
| Safari | 個人 Release の Safari 成果物またはソースビルド | [Safari インストールガイド](./safari-install.md) を参照 |
| QQ / 360 / チーター / Brave / Vivaldi / Opera | 個人 Stable の Chrome パッケージ | [その他のブラウザへのインストールガイド](./other-browser-install.md) を参照 |

::: warning アップストリームのストア版と混同しないでください
Chrome ウェブストア、Edge Add-ons、Firefox Add-ons にある同名の掲載はアップストリームの配布チャネルです。そこからインストールされるのは、この文書で説明する個人強化版ではありません。更新、ブランド、機能は `qianbkk/all-api-hub` の管理対象外です。
:::

## 拡張機能内で更新を確認する

All API Hub の設定ページを開き、バージョンと更新のエリアで **「今すぐ確認」** をクリックします。

個人版は次を確認します。

1. `qianbkk/all-api-hub` の最新 Stable Release。
2. 現在のバージョンと個人 Stable の差。

表示例：

- **現在は最新の正式版です**：対応は不要です。
- **新しいバージョンがあります**：個人 Release ページから対象ブラウザのパッケージをダウンロードします。
- **確認に失敗しました**：GitHub またはネットワークが一時的に利用できない可能性があります。後でもう一度試してください。

個人版が拡張機能を無断でダウンロードまたは置換することはなく、アップストリームのストア版を個人版として表示することもありません。

## 手動インストールと更新

1. インストール元を切り替える前に、設定からバックアップをエクスポートします。
2. [個人 Stable Release](https://github.com/qianbkk/all-api-hub/releases/latest) を開きます。
3. Chrome、Firefox、Safari など、利用ブラウザに対応するパッケージをダウンロードします。
4. ブラウザの要件に従って解凍して読み込むか、プラットフォーム固有の手順を使います。
5. 今後の更新では、新しいパッケージをダウンロードして読み込み先を置き換えるか、旧版を削除して再インストールします。

::: warning 手動版は自動更新されません
個人版は現在ブラウザストアから配布されていないため、ブラウザが個人版の更新を自動配信することはありません。個人リポジトリを Star / Watch し、拡張機能内の確認を定期的に使用してください。
:::

## よくある質問

### 「今すぐ確認」はパッケージを自動ダウンロードしますか？

いいえ。現在のバージョンと個人 Stable を比較し、個人 Release へのリンクを表示するだけです。

### Nightly は長期利用に向いていますか？

向いていません。Nightly は先行テスト用で、未完成の変更や回帰を含む場合があります。

### アップストリームのストア版と個人版を同時にインストールできますか？

明確なテスト目的の場合に限ってください。インストール元によって拡張機能 ID、ストレージ、更新動作が異なる場合があります。先にバックアップを取り、どちらの版を開いているか確認してください。

### 手動インストール版はどう更新しますか？

新しいパッケージをダウンロードし、新しい拡張機能ディレクトリを読み込みます。Chromium 系ブラウザは [その他のブラウザへのインストールガイド](./other-browser-install.md#update-extension) を参照してください。
