# 站点人工验证接力

> 适用于 Cloudflare、Turnstile 或其他要求用户交互的站点验证。个人增强版只负责打开隔离的临时页面并在验证后继续原操作，不破解验证码、不伪造设备信号，也不自动绕过站点安全机制。

## 功能概述

- **按需打开临时页面**：手动识别、手动刷新等用户主动操作遇到验证时，可在标签页或临时窗口中打开目标站点。
- **用户本人完成验证**：需要滑块、点选、Turnstile 或其他人机验证时，请切换到临时页面并按站点要求操作。
- **验证后继续**：站点确认当前浏览器会话后，扩展可继续原来的识别或刷新流程。
- **默认安全设置**：后台自动任务使用临时验证页面的能力默认关闭；自动刷新默认不使用该能力。是否允许弹出窗口、侧边栏或设置页发起接力，可在设置中单独控制。
- **站点级限流**：批量刷新和签到仍遵守站点级限流与有界错峰，避免不必要的重复请求。

## 使用步骤

1. 登录目标站点，在扩展中执行“自动识别”或“手动刷新”。
2. 若提示需要站点验证，按提示打开临时页面。
3. 切换到该页面，由本人完成站点显示的验证；不要使用破解、代答或自动点击工具。
4. 验证成功后返回扩展，原操作会继续；若没有继续，请手动重试一次。
5. 如果验证反复出现，请停止重试，适当增大刷新间隔，并联系站点确认账号或访问限制。

## 打开方式

在 **设置 → 数据刷新** 中可选择临时验证页面的打开方式：

- **当前窗口标签页**：作为非活动标签页加入现有窗口，减少打断。
- **独立临时窗口**：在需要隔离浏览上下文时使用，但可能将浏览器带到前台。

无论选择哪种方式，验证都必须由用户本人完成。

## 注意事项

- 不轮换 IP，不伪造设备指纹，不破解滑块、图片点选或其他 CAPTCHA。
- 不承诺站点一定接受当前会话；站点风控、账号状态和网络环境仍由站点决定。
- 可选 Cookie / Web Request 权限只在用户授权且相应工作流需要时使用，可以随时撤销。
- 若临时页面被浏览器拦截，请检查扩展权限和弹窗设置，不要连续快速重试。

## 常见问题

| 场景 | 处理方式 |
| --- | --- |
| 临时页面没有打开 | 检查浏览器是否拦截弹窗，并确认相关可选权限已由你授权。 |
| 一直停留在 “Just a moment” | 等待站点完成检查；若出现交互验证，请本人完成。长时间无变化时停止重试并稍后再试。 |
| 验证完成后仍报 401/403 | 重新登录站点，确认账号或令牌有效，再手动重试。 |
| 自动任务没有弹出验证页面 | 这是个人增强版的安全默认值；后台自动任务默认不发起人工验证接力。 |
| 频繁出现 429 | 增大刷新间隔，减少并发或批量操作，并遵守站点限制。 |
